# 音频有效性校验（ASR）

**代码位置**：`director/asr_check.py` + `director/routes_asr.py`（前端：`web/js/editor/mixins/asr_check.js`、`web/js/minimax_timeline.js`）

把一个 ASR 模型接到 `asr_model` 口并**运行一次**节点后，**r2v 模式**下的节点上会出现
「音频有效性校验」按钮：点它 → 勾选片段 → 后端按这些片段**当前**的提示词核对它们
**已缓存**的音轨，结果以弹窗展示。整个过程不重新生成任何片段。

## 前置条件

| 项 | 值 |
|---|---|
| 模型类型 | `T8_MOSS_TRANSCRIBE_MODEL` |
| 来源 | `Comfyui-MOSS-Transcribe-Diarize-T8`（与本包放在同一个 `custom_nodes` 下），用 `T8_MOSS_ModelLoader` 的 `model` 口接入 |
| 触发 | r2v 模式下的「音频有效性校验」按钮（非 r2v 任务不显示） |
| 路由 | `POST /minimax/director_opt/asr_check` |

`asr_model` 的句柄由节点在每次运行时登记（`director/asr_runtime.py`），按钮借用它——
所以没跑过节点时按钮会提示先运行一次。未接模型时按钮同样给出明确提示，**不影响出片**；
校验本身抛错也只体现在弹窗文案里。

## 它做了什么

1. 只取**勾选**的那些片段的音轨缓存（没有缓存的列为「已跳过」，不会被当成通过）；
2. 按时间轴顺序拼成一整条，用带说话人分离的 ASR 转写；
3. 从这些片段**当前**的提示词里读出**台词块**，逐说话人与识别结果比对：错误率 + 说话人是否对得上。

## 台词写法

必须严格写成下面这个格式（`re` 必须整段匹配，格式不对就当普通文本）：

```
<Subject 1> (S1) says: <d>[Chinese] 师尊，你一直说你是毒修。</d>
```

| 片段 | 含义 |
|---|---|
| `<Subject N>` | 哪个参考主体在说话 |
| `(SN)` | 这条台词属于哪个说话人 |
| `<d>[lang]…</d>` | 台词正文与语言标签 |

前端会把合法台词渲染成带框的说话人卡片；不合法的不渲染、也不参与校验 —— 写错一个字符只会让
校验跳过这句，不会悄悄变成一条要求。

> 后端的 `SPEECH_RE` 与前端 `minimax_prompt_mentions.js` 里的 `SPEECH_RE` 没有共享代码，
> 改动必须两边同步。

## 长音频

拼接后超过 **30 秒**（`LONG_AUDIO_SECONDS`）会自动改走分块长音频识别
（`runtime.long_audio`），避免一次性识别丢掉尾部语音（那会被误判成「这句台词没说」）。
报告里会写明本次走的是哪条路径；即便走长音频路径，若结果仍被标记 `possibly_truncated`，
报告也会提示。

## 说话人怎么对号入座

识别器按**它自己**的首次出现顺序给说话人编号，与提示词里介绍的顺序无关。因此按「排名」配对：

1. 提示词的说话人按首次出现的台词排序；
2. 识别结果的说话人按首次发声排序；
3. 第 i 名对第 i 名。

`S00` 是「未分配到说话人」标记，**不是**第 0 个人：它不参与排名，单独报告为「未知说话人」，
否则会把所有真实说话人整体错位一位。

## 打分

- 逐说话人、无对齐：该说话人的期望台词按提示词顺序拼接，与该说话人的识别文本按时间顺序比较。
- 错误用 Levenshtein 编辑距离算，token 规则是 **CJK（含假名、谚文）一个字符一个 token**，
  拉丁字母 / 数字连续串算一个 token —— 中文得到 CER，英文得到 WER，且不依赖分词器。
- 阈值 `PASS_RATE = 0.25`：错误率 ≤ 25% 视为这句说对了。
- 期望文本为空的说话人直接跳过（不给免费通过）。

## 读取报告

结论追加在 `report` 末尾，典型内容：

```
音频有效性校验 (ASR): 分块长音频识别 (48.2s > 30s)
  S1: 错误率 12.5% — 通过
  S2: 错误率 41.7% — 未达标
  未知说话人: 1 段未分配
```

## 排错

| 现象 | 处理 |
|---|---|
| 按钮提示「还没有可用的 ASR 模型」 | `asr_model` 没接，或接了但还没运行过一次节点 |
| 弹窗显示「识别失败：未找到 ASR 节点 …」 | ASR 包未安装 / 目录名不匹配；出片不受影响 |
| 弹窗显示「都还没有可识别的音轨缓存」 | 勾选的片段还没生成过，或缓存被「清空缓存」删掉了 |
| 所有台词都判为「没说」 | 检查台词格式是否严格匹配；或说话人编号写错导致配对错位 |
| 尾部台词总被判漏 | 拼接时长超过 30 秒，确认走的是分块长音频路径 |
| 按钮不见了 | 任务类型不是 `r2v`（该按钮只在 r2v 显示） |
